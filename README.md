# Journal

Repository for an independent English-language intellectual magazine/review founded and edited by Ilias Konstantinidis.

> **Take a familiar idea seriously enough that it becomes unfamiliar again.**

The publication is intentionally broad in subject. Its coherence comes from editorial method rather than one topical niche.
