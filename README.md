# Journal

Working repository for an independent English-language intellectual magazine/review.

> **Take a familiar idea seriously enough that it becomes unfamiliar again.**

The publication is being designed as a broad, evidence-driven review of ideas, politics and institutions, technology and science, history, culture and society.

This repository currently contains the editorial/product research baseline and documentation governance. The publication name, public brand, launch platform and final editorial policies are not yet decided.
